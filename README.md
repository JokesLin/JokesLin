## A working archive

农村发展专业硕士研究生，现在住在东南沿海的一座城市。

白天读文献、整理田野笔记、跑数据；晚上打开编辑器，把脑子里那个“要是能有个工具就好了”的念头做成网页。这两件事看起来不搭，但对我来说是同一件事的两端：研究关心人和地方，工具关心它能不能真的被人用起来。

**研究。** 我关心数字农业、森林碳汇和乡村社会。比起宏大叙事，我更想知道一个农户为什么愿意、或者不愿意参与某个项目，一条政策到了村里变成了什么样。方法上偏定量，问卷、回归、Stata 和 Python 交替使用。

**动手。** 从个人站点到 EchoMusic，我做的都是小而完整的东西：能跑、能用、界面不至于难看。前端是自学的，AI 是我现在的主力协作者——很多界面和逻辑是在和模型来回讨论里磨出来的。

**风格。** 不追热点。更新很慢，但留下来的都是跑通过的东西。
